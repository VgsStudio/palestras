09// trivia Questão 1 de 3

Qual serviço da AWS permite executar código sem provisionar servidores?

  • A. Amazon EC2
  • B. Amazon S3
  • C. AWS Lambda
  • D. Amazon RDS
  • C. AWS Lambda
Serverless: você sobe o código, a AWS cuida de toda a infra.
09// trivia Questão 2 de 3

No modelo de responsabilidade compartilhada, quem cuida da segurança "da" nuvem (infraestrutura física)?

  • A. O cliente
  • B. A AWS
  • C. Ambos igualmente
  • D. O provedor de internet
  • B. A AWS
AWS cuida "da" nuvem (hardware, rede, data centers). Cliente cuida "na" nuvem (dados, IAM, configs).
09// trivia Questão 3 de 3

Qual modelo de pricing oferece o maior desconto em troca de compromisso de 1 ou 3 anos?

  • A. On-Demand
  • B. Spot Instances
  • C. Reserved Instances / Savings Plans
  • D. Dedicated Hosts
  • C. Reserved / Savings Plans
Até 72% de desconto com compromisso. Spot dá mais desconto mas pode ser interrompido.
